童年與網路

Created2026-04-14|Updated2026-09-05|Life

Windows XP

小時候玩電腦在的這個開機度條，等待過程不免讓人緊張不已，每每考驗的都是心理素質，雖然跑不完時還是只能崩潰

而聽到 XP 的開機音效時，搭配那藍天綠地的桌面，知道一切都有希望了! 開機音效一響，也就象徵著冒險的開始

作業系統 Windows XP 2001 年推出，微軟 2014 年宣布全面終止對 Windows XP 系統全部版本的技術支援服務，象徵經典的 XP 時代結束，至今也已有長達 25 年，現在回想起來，我爸媽作為自己不太使用電腦的人來說，竟然可以讓家裡擁有當代的作業系統，突然覺得一切都很神奇

還有這個 windows error remix 也很經典

Hinet

小時候就算冒著被臭罵的風險，也會偷偷趁大人不在的時候打開電腦，連上網路的瞬間就像擁有了全世界，短暫脫離了早起上下學的無聊日常

yahoo 奇摩首頁

小時候用電腦的第一站一定會來到這裡，他是那麼年代台灣人搜尋引擎代表，首頁不定時會出現一些奇怪的廣告動畫(汽車,用品…)，熱門搜尋也一定會有美女或緋聞相關的關鍵字

Foxy

Foxy 就是 P2P（peer-to-peer，點對點）檔案分享。它不是像一般雲端硬碟那樣，所有檔案都放在同一台中心伺服器上給大家下載，而是讓每個使用者的電腦同時扮演下載者與上傳者。所以當你下載某個檔案時，系統也可能把你電腦裡可分享的檔案片段提供給其他人，因此使用者越多，理論上來源越多、下載也可能越快，具體來說是這樣

  1. 先加入網路 : 打開 Foxy 之後，程式會先找到其他節點，加入 P2P 網路。研究資料把它描述成一種混合式 P2P 架構，裡面有 ultrapeer 和 leaf node 這類角色，一般使用者多半是 leaf node，先連到較活躍的節點，再透過它們接入整個網路
  2. 輸入關鍵字搜尋 : 當搜尋一個檔名，查詢不一定是送到單一中央伺服器，而是經由網路中的節點幫你轉送、比對，找出哪些人手上有這個檔案，在這種搜尋型 P2P 網路裡，hub／ultrapeer 會幫忙中繼與過濾搜尋結果
  3. 系統回傳有哪些人有這個檔 : 搜尋結果是「目前線上的某些使用者電腦裡有這個檔」。也就是說，檔案實際上散落在很多人的電腦裡
  4. 直接向那些人下載 : Foxy 的下載機制是 P2P 常見做法，會直接從其他 peer 抓資料
  5. 下載完，也可能立刻變成別人的來源，這就是 Foxy 最有名、也危險的地方，我們可能把本來不想公開的檔案一起分享出去

現在回想起來，看到一個簡單的檔案，檔名就被放了那麼多奇奇奇怪怪的關鍵字，真是充滿了惡意與人性阿
